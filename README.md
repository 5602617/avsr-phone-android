# shealive · 手机客户端

[English](README.en.md)

shealive Android 客户端把聊天、语音和悬浮陪伴带到手机上。连接配套 [AstrBot 手机插件](https://github.com/5602617/astrbot_plugin_avsr_phone)后，可以和她交流、配置头像、查看操作进度，并在她需要帮助时接手手机操作。

- **聊天和声音**：文字交流、录音、语音播放，以及离开应用后继续使用的悬浮球。
- **她的头像**：为不同人格设置图片槽，让回复标签切换到你选择的图片。
- **她的屏幕**：查看后台操作进度；主屏使用由你选择，可以接管、停止或拒绝借屏。
- **卡片与等待**：通过交互卡片补充输入、选择或授权；Waiter 将回答交回宿主，恢复原调用。

本仓维护 Android 客户端；账号由宿主插件配置，聊天模型、STT（语音识别）和 TTS（语音合成）需要管理员在宿主自行配置。角色、持久记忆和主动行为由宿主提供。原生 AstrBot 安装插件后不会自动获得 AVSR 持久 Task、记忆或主动 Wake；客户端也不自行实现这些服务。

## 快速开始

需要 Android 13 及以上，以及已经启用的 shealive 宿主插件。先向宿主管理员取得连接地址和手机登录账号；自己部署时，先完成[插件快速开始](https://github.com/5602617/astrbot_plugin_avsr_phone#readme)。

1. **准备客户端**：从 [v0.1.0 发行页](https://github.com/5602617/avsr-phone-android/releases/tag/v0.1.0)下载签名 APK，先核对同页的 `SHA256SUMS`，再安装。Android 可能要求允许浏览器或文件管理器“安装未知应用”。使用 Debug 开发包时，请管理员将插件 `apk_package` 设为 `dev.avsr.phone.debug`，保存并重新加载插件；正式签名或自行签名的 Release 包保持默认 `dev.avsr.phone`。这里只匹配安装包，不改应用 ID。更新请见下方说明。
2. **登录**：在“先认识一下”填入 **宿主地址、账号、密码**，点“登录”。同一局域网中的地址示例为 `http://192.168.1.20:12420`；请换成你自己的宿主地址。账号在宿主手机插件中配置，与 AstrBot 管理页账号分开。
3. **先进入聊天**：登录后选 **“先去聊天，稍后再准备”**。首次文字交流不需要先完成手机操控配对。
4. **收到第一条回复**：在底部“告诉她要做什么”里输入一句“你好”并发送。收到回复后，可以继续聊天，或按下方步骤开启语音、悬浮窗与手机操控。

若连接失败，先核对地址中的 IP 和端口：手机应访问宿主的手机连接端口，默认是 `12420`，不是 AstrBot 管理页端口；`localhost`、`127.0.0.1` 指向手机自身，不能用于连接另一台电脑。局域网地址请保留示例中的 `http://`；省略协议会按 HTTPS 处理，公网地址使用 HTTPS。

## 开启手机操控

1. **首次启动也在手机上完成**，不需要电脑、USB 或另装 Shizuku。手机连上 Wi-Fi，按“让她能用手机”页的 **“开始配对”** 指引进入开发者选项，开启“无线调试”并允许当前网络，再选“使用配对码配对设备”。保持该窗口打开，在本应用通知里输入六位码。配对后 APK 会自动连接无线 ADB、启动内置服务；返回应用看到 **“内置特权服务已运行”** 即已完成，无需再执行启动命令。若已经配对但服务未运行，可点 **“恢复已配对的服务”**；有错误时按页面提示处理。
2. 按“还差几项许可”页完成所需系统设置：**无障碍、悬浮窗、麦克风、通知**；默认数字助理是可选项，不限制后台是建议项。以后可以在“设置 → 手机能力”查看和恢复已配对服务。
3. 选择她使用屏幕的方式，点 **“好了，开始吧”**。以后在设置里的 **“用你的屏幕”** 切换“先问我 / 直接用”。设备和后台行为受手机系统影响。

## 聊天、语音与浮窗

- **聊天**：在底部“告诉她要做什么”中输入，点发送。左侧调节图标进入“设置”。顶部显示连接状态和当前人格名称。
- **语音**：点麦克风“说话”，说完点发送，也可取消录音；语音回复支持“停止语音”和重放。识别和声音需要宿主配置可用的语音提供者。
- **回复方式**：在“设置 → 她怎么回你”选“她来定 / 要语音 / 只要文字”。“不用按住说话”打开后，停顿可发送语音；是否开启由你选择。
- **浮窗**：开启“离开应用后显示她”，或从聊天页“收成悬浮球”。浮窗支持单击打字、双击回应用、按住说话；需要系统悬浮窗许可。

## 她的头像

在“设置 → 她的头像”展开配置，按接入的 Persona 分开设置普通图、图片槽名字、图片和标签分配。标签清单来自宿主；未分配或不认识的标签使用普通图。头像区域和每个槽的标签都可收起。

“移除此人格”会先询问确认，只移除这个人格在本机的头像栏、槽和标签分配等设置；原图文件、其他人格、聊天和任务保留。当前连接的人格仍保留空白设置入口。没有预装头像素材时显示默认占位，用户导入图不作为发布资产。

## 后台操作、她的屏幕与接管

“后台”指她在自己的屏幕中操作，不直接占用你正在看的主屏。聊天页眼睛图标或“设置 → 手机能力 → 看看虚拟屏”会打开 **“她的屏幕”**；这个预览入口用来看进度，不是接管操作。

需要你完成某一步时，会出现 **“这一步需要你来”** 卡片。点“我来处理”进入接管画面，完成后点“处理好了，继续”；也可以“稍后处理”或“结束这件事”。任务运行时界面提供“停止”。

需要使用你的主屏时，“先问我”模式会显示借屏卡，你可以选 **“这次借给你 / 以后都可以用 / 先不用”**，倒计时期间仍可取消。设置“直接用”或输入框旁“这件用主屏”也是明确的使用选择。设备授权卡上的确认以该卡片点按为准，聊天里一句“允许”不能代替点击。

覆盖更新需要相同应用身份与兼容签名。请使用同一发行渠道的更新包；安装失败时先核对签名和版本，不要通过卸载或清数据解决，以免丢失本机设置。自行签名的 APK 通常不能覆盖其他签名的安装。

## 遇到问题

- **登录失败**：检查手机能否访问宿主地址、手机插件端口与账号；账号由插件创建，和 AstrBot 管理账号分开。
- **能聊天但不能说话**：检查麦克风权限及宿主 STT/TTS 提供者。文字聊天可以先使用。
- **能聊天但不能操作**：回到“设置 → 手机能力”检查配对服务、无障碍等状态；查看是否有等待点按的授权卡。
- **切到后台后断开**：检查通知、悬浮窗和系统电池限制；系统强杀或厂商后台策略仍可能中断连接。

普通问题可通过 [Issues](https://github.com/5602617/avsr-phone-android/issues)反馈，附版本、Android/机型、复现步骤及脱敏现象。安全问题请先读 [SECURITY](SECURITY.md)，不要公开凭据、聊天或私人画面。
